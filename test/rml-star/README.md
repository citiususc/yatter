# RML-star

These cases check the translation of YARRRML mappings that produce RDF-star quoted triples.

| Test case | What it covers |
| --- | --- |
| `YARRRML-STAR-TC-0001` | A quoted triple used as a subject map (RMLSTARTC-0001a). |
| `YARRRML-STAR-TC-0002` | A conditionally selected, non-asserted quoted subject (RMLSTARTC-0001b). |
| `YARRRML-STAR-TC-0003` | Nested quoted triples used as subjects (RMLSTARTC-0003a). |
| `YARRRML-STAR-TC-0004` | A non-asserted quoted triple used as a subject (RMLSTARTC-0005a). |
| `YARRRML-STAR-TC-0005` | A non-asserted quoted triple used as an object (RMLSTARTC-0006a). |
| `YARRRML-STAR-TC-0006` | Chained quoted-triple mappings (RMLSTARTC-0008a). |
