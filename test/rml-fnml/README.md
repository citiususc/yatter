# Functions (FNML)

These cases check function mappings, parameter forms, and function-based joins.

| Test case | What it covers |
| --- | --- |
| `YARRRML-FNML-TC-0001` | A lowercase function applied to an object value. |
| `YARRRML-FNML-TC-0002` | A function used to produce a subject value. |
| `YARRRML-FNML-TC-0003` | Nested lowercase and uppercase functions. |
| `YARRRML-FNML-TC-0004` | Reusing a function for multiple object properties. |
| `YARRRML-FNML-TC-0005` | Inline function-call syntax with parameters. |
| `YARRRML-FNML-TC-0006` | Mixing function-call and parameter-map forms. |
| `YARRRML-FNML-TC-0007` | Nested function calls and parameters. |
| `YARRRML-FNML-TC-0008` | A function used in a predicate map. |
| `YARRRML-FNML-TC-0009` | Joining mappings with equality conditions. |
| `YARRRML-FNML-TC-0010` | Joins using quoted and non-asserted mappings. |
| `YARRRML-FNML-TC-0011` | A GREL string-splitting function. |
