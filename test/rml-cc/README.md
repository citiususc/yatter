# Compatibility cases

These cases check translation of collection and gather constructs into the expected RML graph.

| Test case | What it covers |
| --- | --- |
| `YARRRML-CC-TC-0001` | Gathering values as alternatives. |
| `YARRRML-CC-TC-0002` | Gathering values as a bag. |
| `YARRRML-CC-TC-0003` | List shorthand on an object. |
| `YARRRML-CC-TC-0004` | Sequence shorthand on an object. |
| `YARRRML-CC-TC-0005` | A bag gather combined with an explicit object value. |
| `YARRRML-CC-TC-0006` | A list gather combined with an explicit object value. |
| `YARRRML-CC-TC-0007` | Empty values in a gathered bag. |
| `YARRRML-CC-TC-0008` | A gathered list with a boolean-like object value. |
| `YARRRML-CC-TC-0009` | A gathered list with a false object value. |
| `YARRRML-CC-TC-0010` | Gathering list values for subjects. |
| `YARRRML-CC-TC-0011` | List shorthand for subject values. |
| `YARRRML-CC-TC-0012` | Gathering bag values for subjects. |
| `YARRRML-CC-TC-0013` | Gathering list values from multiple references. |
| `YARRRML-CC-TC-0014` | Compact list syntax with multiple references. |
| `YARRRML-CC-TC-0015` | Multiple gathered references with a list strategy. |
| `YARRRML-CC-TC-0016` | Multiple gathered references combined with an explicit value. |
| `YARRRML-CC-TC-0017` | Combining bag inputs into a list. |
| `YARRRML-CC-TC-0018` | Nested gathers with different collection types. |
| `YARRRML-CC-TC-0019` | Conditional gathering of blank-node objects. |
| `YARRRML-CC-TC-0020` | Mapping-based gathering of blank-node objects. |
| `YARRRML-CC-TC-0021` | List gathering inside a named graph. |
| `YARRRML-CC-TC-0022` | IRI objects and list gathering inside a named graph. |
