# Jelly

These tests cover reading, writing, and validating Jelly and other supported output formats.

| Test case | What it covers |
| --- | --- |
| `YARRRML-JELLY-TC-0001` | Reading a Jelly mapping input. |
| `YARRRML-JELLY-TC-0002` | Reading an accepted Turtle input. |
| `YARRRML-JELLY-TC-0003` | Rejecting an unsupported input extension. |
| `YARRRML-JELLY-TC-0004` | Writing and reading Jelly output. |
| `YARRRML-JELLY-TC-0005` | Writing and reading Turtle output. |
| `YARRRML-JELLY-TC-0006` | Writing and reading YAML output. |
