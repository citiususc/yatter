# RML Old

These cases cover common mapping constructs and source formats in YARRRML-to-legacy-RML translation.
The cases use `CORE_OLD` identifiers to distinguish them from current RML-Core.

| Test case | What it covers |
| --- | --- |
| `YARRRML-CORE_OLD-TC-0001` | CSV source mapping, based on R2RML YARRRMLTC-0001. |
| `YARRRML-CORE_OLD-TC-0002` | XML source mapping, based on R2RML YARRRMLTC-0002. |
| `YARRRML-CORE_OLD-TC-0003` | MySQL source mapping, based on R2RML YARRRMLTC-0003. |
| `YARRRML-CORE_OLD-TC-0004` | JSON source mapping, based on R2RML YARRRMLTC-0005. |
| `YARRRML-CORE_OLD-TC-0005` | MySQL source with an external source description. |
| `YARRRML-CORE_OLD-TC-0006` | MySQL source with an internal source description. |
| `YARRRML-CORE_OLD-TC-0007` | CSV source with datatype handling. |
| `YARRRML-CORE_OLD-TC-0008` | Merging mappings by TriplesMap identifier, including inputs without optional sections. |
| `YARRRML-CORE_OLD-TC-0009` | Positive-integer datatype on a constant object. |
| `YARRRML-CORE_OLD-TC-0010` | Class and property maps with a default subject. |
| `YARRRML-CORE_OLD-TC-0011` | GeoSPARQL point geometry with a WKT literal. |
| `YARRRML-CORE_OLD-TC-0012` | An object map with a language tag and term type. |
| `YARRRML-CORE_OLD-TC-0013` | A subject map with a blank-node term type. |
| `YARRRML-CORE_OLD-TC-0014` | A subject map with a graph. |
