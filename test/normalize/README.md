# Normalization

Each case checks that a supported YARRRML shorthand is normalized to its canonical mapping form.

| Test case | What it covers |
| --- | --- |
| `YARRRML-NORM-TC-0001` | Author metadata in short and expanded forms. |
| `YARRRML-NORM-TC-0002` | Named source declarations normalized into mappings. |
| `YARRRML-NORM-TC-0003` | Compact source declarations. |
| `YARRRML-NORM-TC-0004` | Multiple sources and query-formulation fields. |
| `YARRRML-NORM-TC-0005` | Output targets declared on a subject. |
| `YARRRML-NORM-TC-0006` | Compact target declarations. |
| `YARRRML-NORM-TC-0007` | Multiple output targets. |
| `YARRRML-NORM-TC-0008` | Subject values normalized to explicit value maps. |
| `YARRRML-NORM-TC-0009` | Multiple subject values. |
| `YARRRML-NORM-TC-0010` | Compact predicate-object pairs. |
| `YARRRML-NORM-TC-0011` | Multiple compact predicate-object pairs. |
| `YARRRML-NORM-TC-0012` | Object type and value shorthand. |
| `YARRRML-NORM-TC-0013` | Datatype on an object value. |
| `YARRRML-NORM-TC-0014` | Language tag on an object value. |
| `YARRRML-NORM-TC-0015` | Predicate and object values in expanded form. |
| `YARRRML-NORM-TC-0016` | Multiple object values with datatypes. |
| `YARRRML-NORM-TC-0017` | Multiple object values with language tags. |
| `YARRRML-NORM-TC-0018` | Function parameters normalized to explicit parameter maps. |
