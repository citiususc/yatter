# In-memory sources

These cases check YARRRML mappings that use Python data directly as input.

| Test case | What it covers |
| --- | --- |
| `YARRRML-MEMORY-TC-0001` | A Pandas dataframe source. |
| `YARRRML-MEMORY-TC-0002` | A dataframe source without explicit software characteristics. |
| `YARRRML-MEMORY-TC-0003` | The concise form of a dataframe source. |
| `YARRRML-MEMORY-TC-0004` | A Python dictionary source. |
| `YARRRML-MEMORY-TC-0005` | The concise dictionary-source form. |
| `YARRRML-MEMORY-TC-0006` | Multiple dataframes as sources. |
| `YARRRML-MEMORY-TC-0007` | Multiple Python dictionaries as sources. |
| `YARRRML-MEMORY-TC-0008` | A combination of in-memory and local-file sources. |
| `YARRRML-MEMORY-TC-0009` | JSON and XML in-memory sources with structure definers. |
