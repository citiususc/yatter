# Datatypes

These cases check datatype assignment during translation and inverse translation.

| Test case | What it covers |
| --- | --- |
| `YARRRML-DATATYPE-TC-0001` | Taking a literal datatype from a source reference. |
| `YARRRML-DATATYPE-TC-0002` | Building a datatype value from multiple source references. |
| `YARRRML-DATATYPE-TC-INV-0001` | Recovering a datatype reference during inverse translation. |
