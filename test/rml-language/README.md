# Language tags

These cases check language-tagged literals and their inverse translation.

| Test case | What it covers |
| --- | --- |
| `YARRRML-LANGUAGE-TC-0001` | A literal with a fixed English language tag. |
| `YARRRML-LANGUAGE-TC-0002` | A language tag taken from a source reference. |
| `YARRRML-LANGUAGE-TC-0003` | A language tag assembled from multiple references. |
| `YARRRML-LANGUAGE-TC-INV-0001` | Recovering a language-tagged literal during inverse translation. |
| `YARRRML-LANGUAGE-TC-INV-0002` | Recovering a language-tag template during inverse translation. |
